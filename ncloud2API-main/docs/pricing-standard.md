# API 开发报价标准

> 适用场景：第三方系统集成（逆向工程 / 抓包接入），非公开 API 文档项目。

---

## 前置说明

本项目所有接口均需对目标系统进行抓包分析，属于逆向集成工作，有别于对接公开 API 文档的标准开发。每个接口含抓包分析工时，不可压缩。若目标系统升级导致接口结构变更，后续适配按维护费用另计。

---

## 维度一：接口类型基础价

| 接口类型 | 基础价 | 说明 |
|---------|--------|------|
| 读接口 - 列表 | 15 | 调用单个 API，处理分页、过滤条件，返回数组 |
| 读接口 - 详情 | 20 | 调用单个 API，处理嵌套结构（主表 + 明细行） |
| 状态变更 | 15 | 单次操作，入参少，无复杂副作用 |
| 写接口 - 添加 | 60 | 复杂表单提交，字段多，含校验逻辑 |
| 写接口 - 修改 | 添加价 × 0.75 | 本质为添加表单 + 数据预填 + 差量提交，工作量约为添加的 75% |
| 查询汇总 / 报表 | 40 | 多条件过滤 + 汇总统计，响应结构复杂 |

---

## 维度二：复杂度加价

| 复杂度因素 | 加价 |
|-----------|------|
| 含子表（明细行） | +10 |
| 必填校验 / 联动校验逻辑复杂 | +5 ~ +10 |
| 主表字段 ≥ 15 个 | +10 |
| 多操作合并（每增加一个操作） | +5 |
| 需抓包逆向（非公开 API） | +10 ~ +20 |

---

## 维度三：文档要求加价

| 文档级别 | 加价 |
|---------|------|
| 无需文档 | 0 |
| 基本说明（入参 / 出参字段列表 + 示例） | +5 |
| 完整文档（OpenAPI / Swagger 规范 + 字段说明 + 错误码） | +10 ~ +15 |

---

## 计价公式

```
单接口报价 = 基础价 + 复杂度加价合计 + 文档加价
```

---

## 备注

- 以上价格单位与甲方约定币种一致（元 / 美元等，签约前确认）。
- 同一系统内结构相似的接口（如销售订单与发货单为同一模块），可协商打包折扣 10%。
- 接口验收标准：联调通过 + 文档交付，不含甲方系统升级后的维护。
